# 2.5D Multiple Instance Learning Baseline with Attention Pooling

To handle multi-series 3D MRI volumes of varying slice depth and plane orientations within GPU memory constraints, we implemented a 2.5D Multiple Instance Learning (MIL) architecture combining pre-trained 2D CNN backbones (EfficientNet-B2) with learned plane-aware attention pooling.

## Status

accepted

## Context

Knee MRI examinations consist of multiple 3D volumetric series (Sagittal, Coronal, Axial) with variable slice counts (from 15 to 40+ slices per series). Full 3D CNNs (e.g. 3D ResNet, UNet) suffer from prohibitive VRAM consumption, lack rich pre-trained ImageNet weights, and risk overfitting on ~4,400 studies. Simple 2D slice averaging loses spatial continuity across adjacent slices necessary for radiological rules like the two-slice meniscal tear criterion.

## Considered Options

- **Full 3D CNN Backbones (3D ResNet-50 / 3D DenseNet)**: High VRAM cost, limited batch sizes, and no ImageNet transfer learning.
- **2D Slice-Level Classification with Mean Pooling**: Ignores inter-slice context, treating all slices equally regardless of anatomical pathology presence.
- **2.5D Triplet Stacking with Learned Attention Pooling (Selected)**: Stacks consecutive slice triplets `[i-1, i, i+1]` into 3 channels (2.5D) for 2D transfer backbones (EfficientNet-B2), processes 24 center-weighted slices per series, and aggregates slice embeddings via plane-specific `AttentionPooling` heads with plane-presence masking.

## Consequences

- 2.5D stacking natively satisfies the radiological two-slice rule for meniscal tear detection.
- Fast convergence and strong feature transfer from ImageNet pre-trained weights.
- Gradient checkpointing allows training on single-GPU (16GB VRAM) with effective batch size of 8.
- The model outputs raw logits; sigmoid activation is strictly deferred to post-training calibration / inference.
